# 북마클릿 · 이미지 / 동영상 추출 도구 상자

웨일 모바일, Chrome 등에서 사용할 수 있도록 설계한 **통합 북마클릿**입니다. 북마크 하나로 **이미지 추출기**와 **동영상 추출기**를 선택할 수 있습니다.

> GitHub 저장소 이름에는 한글을 사용할 수 없어 실제 저장소 이름은 `bookmarklet`를 권장합니다. 저장소 설명이나 README 제목에 **북마클릿**을 쓰면 됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `launcher.js` | 북마크로 실행할 때 **도구 선택 메뉴**를 표시합니다. |
| `image-picker.js` | 기존 고급 이미지 추출기 (화면 직접 선택, 썸네일, 주소 복사, 저장, ZIP, 심층 검색) |
| `video-picker.js` | 동영상 추출기 (썸네일/주소 목록, 선택, 미리보기, 저장, 선택 ZIP, 심층 검색) |
| `install.html` / `index.html` | **GitHub 계정명을 입력해 짧은 북마클릿을 생성**하는 설치 페이지 (Pages용 `index.html` 포함) |

## 처음 설치 — 휴대폰에서도 가능

1. GitHub에 **Public** 저장소 `bookmarklet`를 만듭니다 (기본 브랜치 `main`). 저장소 설명에는 `북마클릿`이라고 적어도 됩니다.
2. 이 ZIP 파일을 압축 해제하고 `launcher.js`, `image-picker.js`, `video-picker.js`, `install.html`, `index.html`, `README.md`를 **저장소 최상위**에 업로드합니다. ZIP 파일 자체만 올리면 동작하지 않습니다.
3. `install.html`을 기기 브라우저에서 열거나, 아래 북마클릿 템플릿의 `YOUR_USERNAME`을 자신의 GitHub 사용자명으로 바꿉니다.
4. 웨일에서 임의 페이지를 북마크로 추가한 다음, **북마크 편집 → URL**에 짧은 코드를 넣습니다. 북마크 이름은 `북마클릿`으로 설정합니다.
5. 실제 웹페이지를 연 상태에서 주소창에 `북마클릿`을 입력해, **별표 표시가 있는 북마크 검색 결과**를 눌러 실행합니다. (일반 검색 버튼 아님)

### 짧은 북마클릿 템플릿

아래 코드는 한 줄입니다. `YOUR_USERNAME`만 교체하세요.

```js
javascript:(()=>{let s=document.createElement('script');s.src='https://cdn.jsdelivr.net/gh/YOUR_USERNAME/bookmarklet@main/launcher.js';s.onerror=()=>alert('실행 실패: GitHub 파일 또는 CSP를 확인하세요.');document.documentElement.appendChild(s)})()
```

`install.html`에는 **사용자명 입력 + 복사 버튼**이 있어서 직접 수정하지 않아도 됩니다. 원한다면 GitHub Pages를 활성화해 `index.html`을 설치 페이지로 활용할 수도 있습니다.

### 동영상 추출기 사용

- 영상이 보이도록 페이지를 **스크롤**한 뒤 북마클릿을 실행합니다.
- **화면에서 선택**: 일반 `<video>` 요소나 링크를 직접 터치해 골라줍니다. 커스텀 플레이어는 갤러리 선택을 활용하세요.
- **다시 검색 / 심층 검색**: 노출된 `<video>`, `<source>`, `data-*` 속성, 오픈 Shadow DOM, 접근 가능한 iframe, JSON-LD, 메타 태그, 로딩 기록, 일부 인라인 스크립트의 영상 URL을 찾습니다.
- **파일 저장**: 같은 출처 파일은 브라우저 다운로드를 요청합니다. 다른 출처 파일은 CORS가 허용되면 최대 120MB까지 브라우저 메모리에 받아 저장을 시도합니다.
- **선택 ZIP 저장**: 직접 파일 주소인 영상을 **최대 6개, 합계 80MB** 범위에서 ZIP으로 묶습니다. 필요한 원본이 CORS 정책상 접근 가능해야 합니다. 압축 파일은 무압축 ZIP이므로 영상 파일 크기가 크게 줄어들지 않습니다.
- **선택 주소 복사**: 여러 주소를 줄바꿈으로 복사합니다.
- 각 도구 상단의 **☰ 도구 선택**을 누르면 다시 도구 선택 메뉴로 돌아갑니다.
- **iframe 목록**: 접근할 수 없는 다른 출처의 프레임 주소를 표시합니다. 해당 프레임을 새 탭으로 열어 북마클릿을 별도로 실행할 수 있는 경우가 있습니다.

### 추출 가능 범위와 한계

- **MP4 / WebM 등 파일 주소**: 출처와 다운로드 정책에 따라 바로 저장 또는 열기 가능.
- **HLS `.m3u8` / DASH `.mpd`**: 스트리밍 재생목록 **주소**만 확인합니다. 영상 분할 조각을 합치거나 MP4로 변환하지 않습니다.
- **`blob:` / MediaSource**: 일반적인 다운로드용 파일 주소가 아닙니다. 이를 실제 원본 영상 주소로 변환할 수 있다고 보장하지 않습니다.
- **다른 출처 iframe**: 내부 DOM 접근 불가 (동일 출처 정책). 프레임을 새 탭으로 여는 방식만 제공합니다.
- **DRM/암호화/접근 권한**: 우회하지 않습니다. 로그인, 서버 권한, CORS, CSP 및 사이트 다운로드 제한에 따라 실패할 수 있습니다.
- **JavaScript만으로 항상 파일이 내려받아지지는 않습니다.** 브라우저의 파일 저장 정책에 따라 파일이 새 탭에서 열리거나 사용자 확인이 필요할 수 있습니다.
- 일부 사이트의 대용량 동영상은 휴대폰 메모리 제한으로 다운로드할 수 없습니다.

## 도구 추가

새 파일 `new-tool.js`를 저장소에 올리고, `launcher.js`의 `tile(...)` 호출에 메뉴를 한 줄 추가하면 됩니다. 새로운 북마크를 만들 필요는 없습니다.

## 관리 및 보안

- 공개 저장소의 코드는 CDN에서 로딩됩니다. 웹페이지 내부 권한으로 실행되므로 **자신이 관리하는 신뢰할 수 있는 코드만** 저장하고 외부의 임의 수정을 허용하지 마세요.
- 이미지/영상 URL은 현재 브라우저에서만 처리합니다. 저장 기능은 선택한 미디어의 서버에 직접 접근할 수 있으며, 추가적인 외부 수집 서버는 사용하지 않습니다.
- `@main` CDN은 코드 수정이 즉시 반영되지 않을 수 있습니다. 이 경우 CDN 캐시가 갱신된 뒤 재실행하세요.
- 이미지·동영상 사용 시 저작권 및 이용약관을 준수하세요.
