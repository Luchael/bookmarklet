🧰 북마클릿 설치 도우미

웨일·Chrome에서 실행할 이미지/동영상 추출기를 하나의 짧은 북마크로 등록합니다.

① GitHub에 파일 업로드

새 공개 저장소 이름을 bookmarklet로 만들고, 내려받은 ZIP의 압축을 해제한 파일들을 저장소 최상위에 업로드하세요. 기본 브랜치는 main이어야 합니다.

GitHub 저장소 실제 이름에는 한글을 쓸 수 없습니다. 저장소 설명을 ‘북마클릿’으로 적으면 됩니다.

GitHub 저장소 만들기

② 내 GitHub 사용자명 입력

기존 저장소 이름이 다르면 아래 두 번째 입력칸에서 수정하세요.

이름을 입력하면 코드가 생성됩니다.
launcher.js 주소 확인

③ 웨일 북마크에 등록

  1. 웨일에서 임의의 페이지를 북마크에 추가합니다.
  2. 북마크 편집에서 이름을 북마클릿, URL을 방금 복사한 코드로 변경합니다.
  3. 원하는 사이트를 연 후 주소창에서 ‘북마클릿’을 검색하고 별표가 붙은 북마크 항목을 탭하세요.
  4. 메뉴에서 이미지 추출기 또는 동영상 추출기를 선택합니다.

일부 사이트는 콘텐츠 보안 정책(CSP)으로 외부 JS를 막습니다. 그런 페이지에서는 코드가 실행되지 않을 수 있습니다. GitHub CDN의 변경 반영에도 지연이 발생할 수 있습니다.

개인적으로 관리하는 GitHub 저장소에서만 실행하세요. 이 북마클릿은 외부 스크립트를 웹페이지의 권한으로 실행하므로, 저장소 접근 권한을 안전하게 관리해야 합니다.
