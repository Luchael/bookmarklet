웨일 모바일용 이미지 추출기

기존 고급 북마클릿(약 26,000자)이 웨일의 URL 제한에 걸릴 때 사용하는 짧은 버전입니다.

① 갤러리형 (권장)

이미지 목록을 한눈에 보고 원하는 사진의 주소를 확인하거나 저장합니다. 접근 가능한 iframe, CSS 배경 이미지도 일부 검색합니다.

북마크 코드 길이: 1,675자

② 화면 터치형 (초단축)

갤러리가 URL 제한에 걸릴 때 사용하세요. 화면에서 사진을 터치하면 주소를 확인하거나 저장을 시도합니다. 일반 페이지에 적합하며 iframe 내부는 제외합니다.

북마크 코드 길이: 921자

사용 방법

  1. 웨일 모바일에서 북마크 하나를 추가하고 편집합니다.
  2. 북마크 URL을 지운 후 위에서 복사한 코드를 넣습니다.
  3. 원하는 웹페이지를 연 상태에서 해당 북마크를 실행합니다.
  4. 갤러리형에서는 주소 또는 저장을 누릅니다. 터치형에서는 이미지를 터치하여 선택합니다.
참고: 외부 사이트에서 이미지 다운로드를 강제할 수는 없습니다. 일부 이미지는 새 탭으로 열리거나 저장이 차단됩니다. 다른 출처의 iframe, 보안 제한 Canvas 등은 접근 불가합니다. 26,000자 원본의 화면 직접 선택·ZIP 일괄 다운로드 등 모든 기능은 이 짧은 버전에 포함되지 않습니다.
